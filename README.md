# Week 2 – Advanced Data Visualization & Storytelling with Python

## Project
**The Development Story: Income, Health and Population**

This project uses the public Gapminder dataset available through Plotly. Plotly documents the dataset as 1,704 country-year observations with country, continent, year, life expectancy, population, GDP per capita and country codes.

## Deliverables
- `Week2_Advanced_Data_Visualization_Storytelling.docx` – main submission
- `week2_visualization_storytelling.ipynb` – Jupyter notebook
- `week2_visualization_storytelling.py` – Python script
- `gapminder_dataset.csv` – dataset used
- `visualizations/` – static PNG charts and interactive HTML charts

## Visual narrative
1. Life expectancy trend
2. GDP per capita vs life expectancy
3. Population growth
4. Life expectancy distribution
5. Highest GDP per capita countries
6. Interactive global life expectancy map
7. Animated development bubble chart

## Reproducibility
The notebook loads the dataset with `plotly.express.data.gapminder()`, so the analysis can be reproduced without an external download.
